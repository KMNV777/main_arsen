1. ОБЩАЯ ИДЕЯ
--------------------------------------------------------------------------------

Бот — мини-игра в стиле коллекционных карточек (киберспорт / мемы).
Каждая карточка = одна цитата конкретного человека + его фото.
Игрок открывает паки за билеты, собирает коллекцию, обменивает дубликаты
на пыль и соревнуется в таблице лидеров.

Карточки: 121 уникальная цитата (1 цитата = 1 карточка)

Паки:     4 тематических пака, в каждом ровно 2 участника:

3. ВАЛЮТЫ И РЕСУРСЫ
--------------------------------------------------------------------------------

🎫 Билеты (tickets)
  - Стартовый баланс: 5 билетов при первом /start
  - Тратятся на открытие пака: 1 билет = 1 пак
  - Можно получить через обмен пыли (см. раздел 6)
  - Временный бонус в профиле: кнопка «+2 билета» (для тестов)

🔁 Пыль дубликатов (duplicate_dust)
  - Начисляется за каждый дубликат при открытии пака: +1 пыль
  - Тратится в меню «🔁 Обмен»
  - Не уменьшает коллекцию — дубликат не добавляется повторно в user_cards

📚 Коллекция (user_cards)
  - Множество уникальных quote_id, которые игрок уже получил
  - Размер коллекции = главный показатель в таблице лидеров


4. ОТКРЫТИЕ ПАКА
--------------------------------------------------------------------------------

Шаги:
  1. Игрок нажимает «🎁 Открыть пак» и выбирает пак
  2. Проверка: tickets >= 1
  3. Списывается 1 билет
  4. Из пака берутся 2 участника (первые 2 person_id из pack_members)
  5. Для КАЖДОГО участника выдаётся 1 карточка — итого 2 карты за пак

Логика выбора карточки для участника (_pick_quote_for_person):
  - Сначала ищутся цитаты этого человека, которых у игрока ещё НЕТ
  - Если такие есть — случайный выбор из неполученных (приоритет новых)
  - Если все цитаты человека уже собраны — случайный выбор из ВСЕХ
    (это и есть дубликат)

Результат открытия:
  - Новая карточка → добавляется в user_cards, badge «✨ NEW»
  - Дубликат → в коллекцию НЕ добавляется, +1 пыль, badge «🔁 DUP»
  - packs_opened увеличивается на 1

Пример:
  Открыли WYHM Pack → выпали 2 карты (Ваня + Гриша).
  Одна новая, одна повтор → +1 пыль, коллекция +1 карточка.


5. КОЛЛЕКЦИЯ И ПРОСМОТР
--------------------------------------------------------------------------------

«📚 Коллекция»
  - Прогресс по каждому человеку: owned/total + визуальная полоска
  - Кнопки по именам — открыть первую карточку этого человека

«🎴 Моя карточка»
  - Случайная карточка только из уже собранных
  - Если коллекция пуста — подсказка открыть пак

Листание карточек (◀️ / ▶️ / 🎲)
  - Работает по кругу среди карт в коллекции игрока
  - Поиск (🔍) находит карточки по имени или фрагменту цитаты


6. ОБМЕН ДУБЛИКАТОВ (🔁 Обмен)
--------------------------------------------------------------------------------

Константы (collection.py):
  DUST_FOR_TICKET = 3   →  1 билет
  DUST_FOR_CARD   = 5   →  1 случайная новая карточка

Обмен на билет (exchange_dust_for_ticket):
  - Если пыли >= 3: списать 3, добавить 1 билет
  - Иначе — ошибка с текущим балансом

Обмен на карточку (exchange_dust_for_card):
  - Если пыли >= 5: списать 5
  - Выбирается случайная цитата из тех, которых у игрока ещё нет
  - Карточка добавляется в коллекцию, бот отправляет рендер

  Особый случай — полная коллекция (121/121):
  - Новых карт нет → пыль возвращается (+5 обратно)
  - Вместо карты игрок получает 1 бонусный билет
  - Сообщение: «полная коллекция, вернули пыль и дали билет»

Доступ:
  - Кнопка «🔁 Обмен» в главном меню
  - Кнопка в профиле (inline callback exchange_menu)
  - Mini App → вкладка «Обмен» (пыль + P2P)


6B. ОБМЕН С ДРУГИМИ ИГРОКАМИ (P2P, trading.py)
--------------------------------------------------------------------------------

Игрок A предлагает игроку B обмен: отдаёт одну свою карту, опционально
запрашивает конкретную карту B. B принимает (отдаёт запрошенную или любую
выбранную) или отклоняет. A может отменить исходящее предложение.

Поиск партнёра:
  - По @username (регистр не важен)
  - Партнёр должен хотя бы раз написать боту (есть запись в user_profiles)

Ограничения:
  - Нельзя обмениваться с самим собой
  - Максимум 5 активных исходящих предложений на игрока
  - Нельзя отправить два одинаковых pending-предложения одному игроку
  - Карты должны быть в коллекции на момент создания и принятия

Статусы trades.status: pending | accepted | declined | cancelled

При принятии (accept_trade):
  - Атомарный swap: offered → B, give → A
  - duplicate_count у переданных карт сбрасывается (новый владелец получает «чистую» карту)

Уведомления (notifications.py):
  - Получателю — при новом предложении
  - Отправителю — при успешном обмене

Mini App UI (вкладка «Обмен» → «Обмен с игроками»):
  - Создать: @username, выбор своей карты, опционально карта партнёра
  - Входящие: принять / отклонить
  - Исходящие: отменить

API:
  GET/POST /api/trades
  POST     /api/trades/create
  GET/POST /api/trades/partner-cards?username=
  POST     /api/trades/{id}/accept   body: { give_quote_id }
  POST     /api/trades/{id}/decline
  POST     /api/trades/{id}/cancel


7. ТАБЛИЦА ЛИДЕРОВ (🏆 Лидеры)
--------------------------------------------------------------------------------

Критерий сортировки:
  1. Количество уникальных карточек (cards_owned) — по убыванию
  2. При равенстве — packs_opened (сколько паков открыто) — по убыванию
  3. При равенстве — user_id (стабильный порядок)

Показывается топ-10 игроков с хотя бы 1 карточкой.

Отображение имени (format_player_name):
  1. display_name из Telegram (full_name), если есть
  2. Иначе @username
  3. Иначе «Игрок #XXXX» (последние 4 цифры user_id)

Имя обновляется при любом действии через touch_user()
(/start, открытие пака, профиль, обмен, лидеры).

Место игрока (get_user_rank):
  - Считается сколько игроков имеют больше карточек + 1
  - Если карточек 0 — места нет (None)

Доступ:
  - Кнопка «🏆 Лидеры» в главном меню
  - Кнопка в профиле (inline callback leaderboard)


8. ПРОФИЛЬ (👤 Профиль)
--------------------------------------------------------------------------------

Показывает:
  - Место в рейтинге (если есть карточки)
  - Баланс билетов и пыли
  - Прогресс коллекции: cards_owned / total (121)
  - Число открытых паков
  - Прогресс по каждому паку (owned/total внутри пака)
  - Подсказку по курсам обмена

Inline-кнопки: Обмен, Лидеры, +2 билета (бонус).


9. КАРТОЧКА (рендер)
--------------------------------------------------------------------------------

Формат: вертикальное JPEG 900×1280
  - Верх: фото человека (или placeholder по имени файла)
  - Низ: имя + цитата
  - Badge «✨ NEW» для новых карт при открытии пака

Фото: quotes_bot/assets/photos/*.jpg
Обновление: /photo Имя или отправка фото с подписью-именем в Telegram.


10. СХЕМА БАЗЫ ДАННЫХ
--------------------------------------------------------------------------------

people          — персонажи (name, photo_url, …)
quotes          — цитаты (person_id, text)
packs           — паки (slug, name, emoji, description)
pack_members    — связь пак ↔ человек (many-to-many, по 2 в паке)
user_profiles   — профиль игрока:
                    user_id, tickets, packs_opened, duplicate_dust,
                    username, display_name, created_at
user_cards      — коллекция: (user_id, quote_id) — только уникальные карты
meta            — версия seed и служебные ключи


11. ПОТОК ДАННЫХ (кратко)
--------------------------------------------------------------------------------

  /start
    → ensure_user (5 билетов) + touch_user (имя для лидеров)

  Открыть пак
    → spend_ticket(-1)
    → для 2 участников: pick quote → add_card ИЛИ add_dust
    → packs_opened +1
    → отправка 2 JPEG-карточек + итог

  Дубликат
    → user_cards не меняется
    → duplicate_dust +1

  Обмен 3 пыли
    → duplicate_dust -3, tickets +1

  Обмен 5 пыли
    → duplicate_dust -5, random unowned quote → user_cards

  Лидеры
    → SELECT COUNT(user_cards) GROUP BY user_id ORDER BY count DESC


12. ГЛАВНОЕ МЕНЮ БОТА
--------------------------------------------------------------------------------

  🎮 Играть          — Telegram Mini App (основной режим)
  🎁 Открыть пак    — выбор пака, списание билета, 2 карты (запасной режим в чате)
  📚 Коллекция      — прогресс и просмотр по людям
  🎴 Моя карточка   — случайная из коллекции
  👤 Профиль        — баланс, прогресс, рейтинг
  🔁 Обмен          — пыль → билет / карта
  🏆 Лидеры         — топ-10 коллекционеров
  🔍 Поиск          — поиск по имени или цитате

  Кнопка меню слева от поля ввода (🎮 Играть) также открывает Mini App.


13. TELEGRAM MINI APP
--------------------------------------------------------------------------------

Фронтенд: quotes_bot/webapp/static/ (HTML/CSS/JS + telegram-web-app.js)
Бэкенд:    quotes_bot/webapp_server.py (aiohttp, порт WEBAPP_PORT=8765)
Авторизация: заголовок X-Telegram-Init-Data, проверка подписи (webapp_auth.py)

API:
  GET  /api/profile
  GET  /api/packs
  POST /api/packs/{id}/open
  GET  /api/collection
  GET  /api/leaderboard
  POST /api/exchange/ticket
  POST /api/exchange/card
  GET/POST /api/trades
  POST /api/trades/create
  GET/POST /api/trades/partner-cards
  POST /api/trades/{id}/accept|decline|cancel
  POST /api/cards/{quote_id}/disintegrate
  GET  /api/card/{quote_id}/image

Настройка:
  WEBAPP_URL=https://your-domain   (обязательно HTTPS для Telegram)
  BotFather / setChatMenuButton → Web App URL

При запуске python3 -m quotes_bot поднимаются и бот, и HTTP-сервер Mini App.


14. ФАЙЛЫ КОДА (где что лежит)
--------------------------------------------------------------------------------

  collection.py     — вся игровая логика (паки, обмен, лидеры, профиль)

  keyboards.py      — кнопки меню и inline-клавиатуры
  card_renderer.py  — генерация JPEG карточки


14. ЗАПУСК И ОБНОВЛЕНИЕ ДАННЫХ
--------------------------------------------------------------------------------

  python3 -m quotes_bot

При старте:
  - init_db() — создаёт/мигрирует таблицы
  - seed_database() — заливает людей/цитаты/паки если изменился SEED_VERSION
  - import_inbox_photos() — подхватывает фото из assets/photos/inbox/
  - generate_all_placeholders() — placeholder если фото нет

После правки seed.py — увеличить SEED_VERSION и перезапустить бота.
