# Quotes Bot — карточки людей с цитатами

Telegram-бот с **вертикальными карточками**: сверху фото, снизу ник и цитата.  
**1 цитата = 1 карточка.**

## Возможности

- Вертикальная карточка: фото → ник → цитата
- Случайная карточка и листание ◀️ / ▶️ по всем цитатам
- Список всех карточек
- Поиск по имени или тексту цитаты

## Быстрый старт

```bash
pip install -r quotes_bot/requirements.txt
cp quotes_bot/.env.example .env
# укажите TELEGRAM_BOT_TOKEN в .env
python -m quotes_bot
```

При запуске создаются база SQLite, placeholder-фото (если файлов ещё нет) и начальные карточки.

## Логотип бота

Файл: `quotes_bot/assets/bot_logo.png` (512×512, киберспорт + цитаты).

Чтобы поставить аватар в Telegram:
1. Открой [@BotFather](https://t.me/BotFather)
2. `/mybots` → выбери бота → **Edit Botpic**
3. Загрузи `bot_logo.png`

При старте бот также обновляет имя и описание через API.

## Команды бота

| Действие | Описание |
|----------|----------|
| `/start` | Приветствие |
| `/photo` | Как обновить фото человека |
| 🎴 Случайная карточка | Случайная цитата |
| 📚 Все карточки | Список всех карточек |
| 🔍 Поиск | Поиск по тексту |

### Обновление фото через Telegram

Отправь боту фото с подписью — **точным именем** человека:

```
[фото] + подпись: Машинка
```

Фото автоматически обрежется под вертикальную карточку.

Также можно положить файл в `quotes_bot/assets/photos/inbox/mashinka.jpg` и перезапустить бота.

## Данные

Люди и цитаты — в `quotes_bot/seed.py`.  
После правок перезапустите бота: версия seed обновит базу автоматически.
