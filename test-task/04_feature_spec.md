# ТЗ: Загрузка ресурса в Грузовой Шаттл

| | |
|---|---|
| **Проект** | AstroCrop |
| **Фича** | Грузовой Шаттл (аналог поездов в Township) |
| **Скоуп ТЗ** | Часть функциональности — загрузка одного ресурса в один слот трюма |
| **Автор** | Junior PM&GD |

> Что хочу получить: программист, прочитавший этот документ, должен реализовать ровно то, что описано — без додумывания. Что вне скоупа: запуск шаттла, кулдаун полёта, выдача награды.

---

## 1. Зачем это нужно

Игрок производит на ферме ресурсы (кислород, еду, минералы) и должен сдавать их в Шаттл. Сейчас мы описываем самое сердце фичи — **момент, когда игрок берёт один ресурс со склада и кладёт его в один слот трюма**. От того, насколько понятно сделана эта микро‑операция, зависит ощущение от всей фичи.

---

## 2. Что видит игрок

> *(прямой ответ на первый вопрос брифа)*

На экране Шаттла игрок видит карточку слота. В одной карточке должно быть видно три вещи: **что сдавать**, **сколько надо** и **сколько у меня есть**. Плюс понятная кнопка действия.

Состав карточки:

1. **Иконка ресурса** — крупная (≈ 96×96).
2. **Название ресурса** — одной строкой под иконкой (например, «Кристалл замёрзшего метана»).
3. **Сколько надо** — крупное число в формате `сколько уже загружено / сколько надо всего` (например, `3 / 5`).
4. **Прогресс‑бар** под счётчиком — наглядная заливка, как далеко игрок до закрытия слота.
5. **Сколько есть у игрока** — мелкая строка `У тебя: N`. Если `N = 0`, строка подсвечивается красным.
6. **Кнопка действия** — одна, см. раздел 3.
7. **Галочка «Готово»** — появляется поверх карточки, когда слот полностью заполнен.

Как это выглядит:

```
 ┌──────────────────────────────┐
 │       [ icon 96×96 ]         │
 │   Кристалл замёрзшего метана │
 │                              │
 │            3 / 5             │
 │       ▓▓▓▓▓▓░░░░░░           │
 │       У тебя: 2              │
 │                              │
 │      [   Загрузить   ]       │
 └──────────────────────────────┘
```

---

## 3. На какую кнопку нажимает игрок

> *(прямой ответ на второй вопрос брифа)*

В карточке слота есть **одна кнопка** — `Загрузить`. У неё четыре варианта поведения, и я хочу, чтобы игрок никогда не задумывался «что мне сейчас делать»: правильное действие подсказывает сама кнопка.

| Что у игрока на складе | Как выглядит кнопка | Что происходит по тапу |
|------------------------|---------------------|--------------------------|
| **Хватает на весь слот** | Зелёная `Загрузить` | Слот заполняется до конца. Со склада списывается ровно столько, сколько было нужно. На карточке появляется галочка «Готово». |
| **Есть, но не на весь слот** | Жёлтая `Загрузить (+N)`, где `N` — сколько есть у игрока | В слот докладывается всё, что есть на складе. Склад уходит в 0, слот переходит в стейт «не хватает» (см. раздел 4). |
| **Совсем нет ресурса** | Серая, нажать нельзя. Рядом появляется синяя кнопка `Купить за He‑3` | См. раздел 4 — это сценарий «не хватает». |
| **Слот уже закрыт** | Кнопка скрыта, вместо неё галочка «Готово» | Тап ничего не делает. |

После любой загрузки карточка перерисовывается сразу: меняются цифры, прогресс‑бар, при необходимости — внешний вид кнопки.

---

## 4. Что происходит, если ресурса не хватает

> *(прямой ответ на третий вопрос брифа)*

Это самая чувствительная часть фичи: тут игрок либо застревает, либо платит, либо идёт что‑то делать. Я хочу, чтобы у игрока всегда было **минимум 2 пути**: бесплатный и платный.

**Что игрок видит, когда на складе 0:**

- Кнопка `Загрузить` серая, нажать нельзя. Если игрок всё же тапнул — лёгкая тряска и подсказка «Не хватает ресурса. Произведи на ферме или купи за He‑3».
- Счётчик `У тебя: 0` подсвечен красным.
- Рядом появляется синяя кнопка **`Купить (N) за 💎 He‑3`**, где `N` — сколько ещё нужно положить в слот.

**Платный путь — покупка за премиум‑валюту He‑3:**

1. Тап по `Купить` открывает окно подтверждения с двумя кнопками `Отмена` / `Купить`.
2. Цена считается просто: `сколько не хватает × цена за единицу` (цена за единицу задаётся в конфиге для каждого ресурса).
3. Если He‑3 хватает — на `Купить` валюта списывается, слот сразу закрывается полностью.
4. Если He‑3 не хватает — кнопка `Купить` превращается в `+ Пополнить` и ведёт в магазин премиум‑валюты. После пополнения игрок возвращается на экран Шаттла и может повторить покупку.
5. Тап `Отмена` ничего не делает — деньги не списаны, прогресс слота не изменился.

**Бесплатный путь:** игрок может в любой момент закрыть экран Шаттла и пойти производить ресурс на ферме. Прогресс слота сохраняется. Когда ресурс появится на складе, кнопка `Загрузить` снова станет активной.

**Важно:** если игрок открыл окно покупки, а в это время фабрика как раз выдала готовый ресурс — после закрытия окна состояние кнопки нужно пересчитать. Иначе игрок может купить за He‑3 то, что у него уже есть на складе.

## 5. Функциональные требования

| ID | Требование |
|----|------------|
| FR‑1 | В карточке слота должны одновременно отображаться: иконка ресурса, название, `загружено / требуется`, прогресс‑бар, `У тебя: N`. |
| FR‑2 | Когда `У тебя: 0`, эта строка подсвечивается красным. |
| FR‑3 | Кнопка `Загрузить` имеет 4 состояния (зелёная / жёлтая / серая / скрыта), как описано в разделе 3. |
| FR‑4 | Тап по зелёной `Загрузить` закрывает слот: списывает со склада ровно столько, сколько нужно, ставит галочку «Готово». |
| FR‑5 | Тап по жёлтой `Загрузить (+N)` докладывает в слот всё, что есть на складе, и переводит карточку в состояние «не хватает». |
| FR‑6 | Когда ресурса нет совсем, рядом с серой кнопкой `Загрузить` появляется кнопка `Купить (N) за He‑3` с правильно посчитанной ценой. |
| FR‑7 | Тап по `Купить за He‑3` всегда открывает окно подтверждения; покупка не происходит без явного подтверждения. |
| FR‑8 | Если He‑3 хватает — после подтверждения слот закрывается полностью, валюта списывается. Полу‑покупок не бывает. |
| FR‑9 | Если He‑3 не хватает — игрок отправляется в магазин премиум‑валюты с пометкой, зачем он туда идёт. |
| FR‑10 | Прогресс слота сохраняется при выходе с экрана и при перезапуске приложения. |
| FR‑11 | После любого действия (загрузка / покупка / возврат с магазина / закрытие окна подтверждения) карточка перерисовывается, и состояние кнопки пересчитывается. |
| FR‑12 | Выгрузить ресурс из слота назад на склад **нельзя** — это сделано намеренно, чтобы загрузка ощущалась как обязательство. |

---

## 6. Критерии приёмки

| ID | Критерий |
|----|----------|
| AC‑1 | Открыл экран — за секунду вижу: иконку, название, `3 / 5`, прогресс‑бар, `У тебя: 2`. |
| AC‑2 | На складе достаточно — кнопка зелёная, один тап закрывает слот, появляется галочка «Готово». |
| AC‑3 | На складе меньше, чем надо — кнопка жёлтая, цифра в скобках совпадает с тем, сколько у меня на складе. После тапа склад уходит в 0, кнопка перекрашивается в серую. |
| AC‑4 | На складе 0 — кнопка `Загрузить` серая, рядом видна `Купить (N) за He‑3` с понятной ценой. |
| AC‑5 | Тап по `Купить` всегда сначала показывает окно подтверждения. |
| AC‑6 | Если He‑3 хватает — после подтверждения слот закрылся, He‑3 списан ровно на цену, других списаний нет. |
| AC‑7 | Если He‑3 не хватает — открывается магазин премиум‑валюты; экран Шаттла на фоне сохраняет прогресс. |
| AC‑8 | Если в момент диалога покупки ресурс пришёл на склад (например, фабрика доделала) — после закрытия диалога кнопка автоматически перекрашивается из серой в зелёную/жёлтую. |
| AC‑9 | Закрыл и открыл приложение — карточка слота показывает то же самое, что и до закрытия. |
| AC‑10 | Я нигде не могу «вытащить» ресурс из слота обратно на склад. |
| AC‑11 | На любом тексте экрана нет «английских хвостов» — всё переведено через локализацию. |

## 7. Открытые вопросы (фиксирую как есть)

1. Цена в He‑3 за единицу для каждого ресурса — нужно отдельное обсуждение с экономистом. На время разработки используем плейсхолдер из конфига.
2. Нужна ли отдельная подсказка «впервые встречаешь этот ресурс — вот где его делают»? Если да — это отдельная задача, в текущий скоуп не включаю.
3. Анимации (как именно «летит» ресурс в слот, как пульсирует галочка) — обсуждаем с художниками отдельно. В коде заложить точки‑хуки на эти анимации, но без них фича всё равно должна работать.
