## Ключевые цифры ландшафта

- **20+ информационных систем** в продуктивной/тестовой эксплуатации (без учёта ВЫВОД/ОТКЛЮЧЕНА).
- **2 947 пользователей** ИС ABAI в 8 ДЗО + Корпоративный центр.
- **48 ДЗО + ДОТОС** — охват ИСОТ (HSE).
- **43 ДЗО** — охват Compliance Control.
- **44 потока данных** в реестре (раздел «Потоки/Данные» документа).
- **Хостинг:** ТОО «Qazcloud», 2 VDC (Koshy, Aqqol) + on-prem (АНПЗ) + локальная инфра ДЗО.
- **3 системы в стадии вывода/отключения:** Электронный архив (Documentum), Санау, Бюро пропусков.

## Легенда

- 🟢 PROD — продуктивная эксплуатация
- 🟡 TEST — тестовая среда / стадия внедрения
- 🔴 ВЫВОД / ОТКЛЮЧЕНА
- 🛡️ ЭЦП — интегрировано с НУЦ РК (TSP/OCSP)
- 🏛️ ГОС — интеграция с государственными системами (ЕСЭДО, ГБД, data.egov.kz, nationalbank.kz)
- ⚠️ — отмеченный в документе риск или техдолг

## Критические наблюдения (top-of-mind)

1. **Отсутствие API Gateway, MFA, секрет-менеджера, WAF** во всех системах ДПППС
   (исключения: Vault — только BoardMaps; WAF — только БДА).
2. **ABAI — псевдо-модульность**: 17 «модулей» работают на единой БД `abaiprot` (PostgreSQL).
3. **Архаичная цепочка SCADA-буферов через MySQL dbLink**: SCADA ДЗО → MySQL ЭМГ → MySQL КТМ → MySQL SCADA сервер КМГ → ABAI.
4. **Устаревшие ОС**: CentOS 7 (ABAI, EOL), Ubuntu 14 (АСДЦ web), Win Server 2012 R2 (АСДЦ — 3 сервера).
5. **АСДЦ — legacy mix**: AngularJS + Knockout + PHP + Razor + .NET, MS SQL 2014.
6. **Единая физическая платформа ИСОТ + УТО + Work** — single point of failure.
7. **Внешние администраторы** ИСУП и Интранета (ТОО «KMG DIGITAL»): учётки в AD отключены, но остались в Remote Desktop Users.
8. **Procu/Price** — нет бэкапов, логирования, метрик, алертов (по паспорту).
9. **ABAI бэкапы PostgreSQL** хранятся в окружении Test/QA, нет DR-плана с RTO/RPO.
10. **Покрытие телеметрией ~10% фонда скважин** — ограничивает real-time модули и цифровые двойники.
