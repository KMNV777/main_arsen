6. Риски и технический долг (по документу)

Из раздела «Известные критические узкие места ИТ-ландшафта» (вопрос 20 реестра).
1. ABAI — псевдо-модульность. 17 «модулей» работают на единой БД abaiprot. Изоляции и истинной модульности нет.
2. Устаревший стек ABAI. CentOS 7 EOL, Python/Django/Laravel/Hadoop/Spark/Kafka/Druid версий 2021–2022, ZooKeeper, NameNode, HAProxy, Logstash.
3. Множественные SPOF. PostgreSQL/ZooKeeper/NameNode/Druid в ABAI; MS SQL 2014 в АСДЦ.
4. Бэкапы PostgreSQL ABAI размещены в окружении Test/QA; нет DR-плана с RTO/RPO; нет автоматического failover (Patroni/pgBouncer).
5. Архаичная интеграция SCADA через цепочку MySQL-буферов по dbLink: SCADA→ЭМГ→КТМ→СУБД КМГ→ABAI.
6. Отсутствие API Gateway, circuit breaker, retry-политик во всех системах ДПППС.
7. Отсутствие MFA, WAF (кроме БДА), секрет-менеджера (кроме BoardMaps).
8. GPU-воркеры IBM POWER 9 в ABAI: <1 ТБ диска для ML-задач + ppc64le ограничивает CUDA и Python-экосистему.
9. Нет Kubernetes в ABAI (только Docker+Portainer); единственный K8s — в СДД.
