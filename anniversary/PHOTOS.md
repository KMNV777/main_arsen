# Куда класть ваши рисунки

Положи файлы в `assets/photos/` с такими именами:

| Файл | Что поставить |
| --- | --- |
| `hero.jpg` | Поцелуй (титул) |
| `q1.jpg` | Венеция / селфи у каналов |
| `q2.jpg` | Рим / Колизей |
| `q3.jpg` | Поцелуй (или снова Венеция) |
| `q4.jpg` | Рим (или снова Колизей) |
| `finale.jpg` | Поцелуй |

Форматы ок: `.jpg`, `.jpeg`, `.png`, `.webp` — главное совпало имя (или поправь пути в `index.html`).
