# С праздником, любовь моя

Лендинг-викторина к годовщине отношений: титульная страница и 4 квартала по 4 вопроса.

## Как открыть локально

Из папки `anniversary`:

```bash
python3 -m http.server 8080
```

Затем открой [http://localhost:8080](http://localhost:8080).

## Свои фото

Положи снимки в `assets/photos/`:

| Файл | Где используется |
| --- | --- |
| `hero.jpg` | Титульная страница |
| `q1.jpg` … `q4.jpg` | Фоны кварталов |
| `finale.jpg` | Финальный экран |

## Вопросы

Тексты и правильные ответы — в `js/quiz.js` (объект `quarters`). Можно спокойно править под вашу историю.
