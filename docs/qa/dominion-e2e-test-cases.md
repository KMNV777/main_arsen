### TC-ADM-001: Создание definition предмета Dominion

| Поле | Значение |
|------|----------|
| **ID** | TC-ADM-001 |
| **Модуль** | Админка / Dictionary |
| **Приоритет** | P1 |
| **Тип** | E2E |

**Предусловия:**
1. Авторизован пользователь `U-ADMIN`.
2. В dictionary нет definition с тестовым именем `TC_TEST_HELMET_C`.

**Шаги и ожидаемые результаты:**

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть Админка → Dictionary → Создать предмет | Открыта форма создания definition |
| 2 | Заполнить: name=`TC_TEST_HELMET_C`, slot=`head`, rarity=`Common`, traits=`repairable,sellable`, game_code=`dominion`, base_price=`1000`, durability_loss_per_match=`28`, buff/debuff тексты | Поля принимают значения без ошибок валидации |
| 3 | Нажать «Сохранить» | Definition создан; отображается в списке каталога |
| 4 | Выполнить Grant предмета тестовому игроку `U-F2P-LEAD` | Предмет появляется в GetInventory(game=dominion) |
