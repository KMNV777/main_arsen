# Справочник систем и компонентов схем ИТ-ландшафта ЭМГ

Документ предназначен для бизнес-заказчика и проектных команд: объясняет, что означает каждый блок на схемах, зачем он нужен и как используется в работе.

Основные схемы:
- [`architecture-emg-integrations.md`](architecture-emg-integrations.md)
- [`it-landscape-emg.md`](it-landscape-emg.md)

---

## 1) Компоненты схемы (блоки верхнего уровня)

| Компонент схемы | Что включает | Как используется бизнесом |
|---|---|---|
| Организационный контур | КЦ КМГ, АО «Эмбамунайгаз», КМГИ | Определяет зоны ответственности и владельцев процессов |
| Ядро цифровизации ЭМГ | ABAI, ИМ, АСДЦ, ИС УТО ЭМГ | Операционное управление добычей, телеметрией и транспортом |
| Корпоративные ИС | SAP, САПФИР, ИСОТ, СДД, Team, Интранет, ИСУП и др. | Поддержка финансов, договоров, HSE, управления проектами и корпоративных сервисов |
| Технические интеграции | AD, КХД, АСУНСИ, ИСЭЗ, интеграционная шина | Единые учетные записи, справочники, обмен данными и консолидация |
| Промышленный контур | OPC DA/UA, Modbus, производственные БД, аналитика | Сбор и передача фактических данных с месторождений |
| Идентификация и доступ | Active Directory, LDAP-подключенные ИС | Единый вход пользователей и централизованное управление доступом |
| Информационная безопасность | Solar Dozor, Forcepoint, FUDOPAM, Exchange-контур | Контроль утечек, веб-трафика, привилегированного доступа и почтовых рисков |
| Документооборот и архив | Directum/САПФИР, Alfresco, электронные архивы | Юридически значимый документооборот, хранение и поиск документов |
| Финансы и планирование | SAP ERP, SAS-FM, FC, банки, Нацбанк, ЭСФ, Platts | Финансовый учет, бюджетирование, внешняя отчетность и ценовые данные |
| Кадры и персонал | УП, 1С зарплата, E-Pass | Кадровый учет, начисления, учет сотрудников и пропускной режим |
| Операционные системы ЭМГ/КМГ | ABAI, АСДЦ, УТО, Argus, КГИС, БДА, AVR, sPoint | Производственные процессы, транспорт, активы и операционные сервисы |
| Корпоративный контур КМГ | Team, Интранет, ИСУП, Compliance, СДД | Коммуникации, проекты, контроль соответствия и договорная деятельность |
| НСИ и закупки | Procu/Price, АСУНСИ, ИСЭЗ | Сквозной закупочный процесс и контроль справочников |
| Слои L1-L4 ABAI/ИМ | L1 источники, L2 протоколы, L3 интеграция, L4 сервисы | Поясняет путь данных: от оборудования до управленческой аналитики |

## 2) Справочник систем

### 2.1 Платформы и интеграционные узлы

| Система / компонент | Что это | Как используется | Ключевые связи |
|---|---|---|---|
| SAP ERP | Центральная ERP-платформа | Финансы, учет, закупки, кадровый контур, обмен с внешними сервисами | АСУНСИ, УТО, AVR, 1С, FC, банки, Нацбанк, ИС ЭСФ, архивы |
| Active Directory (AD) | Корпоративный каталог пользователей | Единая аутентификация и роли доступа | Directum, Alfresco, КГИС, Procu, E-Pass, Жулдыз, DLP, FUDOPAM |
| АСУНСИ | Система нормативно-справочной информации | Централизует и синхронизирует НСИ | SAP ERP, Procu |
| ИСЭЗ | Контур электронных закупок | Поддерживает закупочные процедуры | Procu, справочники |
| КХД АО НК КМГ | Корпоративное хранилище данных | Консолидация данных для аналитики и отчетности | sPoint, САПФИР и другие источники |
| Интеграционная шина (SAP PO/XML/CSV/SOAP) | Транспорт интеграций | Стандартизирует обмен между системами | SAP и смежные ИС |

### 2.2 Производственные и операционные системы

| Система / компонент | Что это | Как используется | Ключевые связи |
|---|---|---|---|
| ИС ABAI | Производственная платформа ЭМГ | Мониторинг добычи, отчеты, производственная аналитика | ИМ, ИСОТ, САПФИР |
| Интеллектуальное месторождение (ИМ, cmv2) | OT-хаб данных месторождений | Сбор телеметрии и передача в аналитические сервисы | OPC/Modbus/SQL-источники, аналитика, packet_service |
| АСДЦ | Диспетчерский аналитический контур | Оперативный контроль и диспетчеризация | ABAI/ИМ |
| ИС УТО ЭМГ | Локальная система транспортного блока ЭМГ | Передача данных в корпоративный транспортный контур | ИС УТО |
| ИС УТО | Корпоративная система транспортного обеспечения | Управление транспортными объектами и операциями | SAP ERP, Argus, УТО ЭМГ |
| Argus Pro | GPS-мониторинг транспорта | Передает данные о транспорте и маршрутах | ИС УТО |
| sPoint | Операционная система по нарядам/операциям | Формирует данные для корпоративной аналитики | КХД |
| БДА | База данных активов | Управление сведениями об активах | SAP ERP |
| AVR+SAP | Контур актов выполненных работ | Обмен по актам и договорам | SAP ERP |
| КГИС | Корпоративная ГИС | Пространственные данные и карты объектов | AD |
| Жулдыз | Производственный мониторинг | Доступ пользователей и прикладная аналитика | AD |
| SCADA | Данные по оборудованию | Передача технологических данных в учетный контур | SAP ERP |

### 2.3 Документооборот, HSE и корпоративные сервисы

| Система / компонент | Что это | Как используется | Ключевые связи |
|---|---|---|---|
| Directum | СЭД/BPM | Согласования, поручения, маршруты документов | AD, САПФИР |
| САПФИР | Корпоративный документооборот КМГ | Договорные и служебные документы | Directum, AD, КХД |
| Alfresco ECM | Система управления контентом | Хранение и поиск документов | AD |
| Электронный архив (Азия-Софт) | Архивный контур ЭМГ | Архивное хранение и выдача документов | CMIS, SAP |
| Documentum | Корпоративный архив | Обмен карточками договоров и первичкой | SAP ERP |
| СДД | Договорное делопроизводство | Подготовка и сопровождение договоров | AD, корпоративные сервисы |
| ИСОТ / ЭНД | HSE-контур | Охрана труда, события и нарушения СИЗ | ABAI, AD |
| Портал Team | Корпоративный портал | Коммуникации и кадровые сервисы | AD |
| Интранет | Внутренний портал | Новости, сервисы, внутренние процессы | AD |
| ИСУП | Система управления проектами | Планирование и контроль проектных инициатив | Корпоративные контуры КМГ/ЭМГ |
| Compliance Control | Система комплаенс-контроля | Контроль соответствия требованиям | Корпоративный контур КМГ |

### 2.4 Финансы, кадры, закупки и внешние контуры

| Система / компонент | Что это | Как используется | Ключевые связи |
|---|---|---|---|
| SAS-FM | Финансовое моделирование/планирование | Подготовка и передача финмоделей | SAP ERP |
| FC | Финансовая консолидация | Сведение показателей группы | SAP ERP |
| 1С (зарплата) | Расчет зарплаты | Получает данные из ERP-контура | SAP ERP |
| ПК «Управление персоналом» | Кадровая система | Табельные номера, кадровые процессы | SAP ERP, корпоративный портал |
| E-Pass | Пропускной режим | Учет проходов и доступа персонала | AD |
| Procu / Price | Закупочная система | Закупочные процедуры и ценовые процессы | АСУНСИ, ИСЭЗ, AD, SAP |
| Нацбанк | Внешний поставщик курсов | Курсы валют для учета | SAP ERP |
| БВУ (банки) | Банковские системы | Выписки и платежные транзакции | SAP ERP |
| ИС ЭСФ | Сервис счетов-фактур | Обмен данными по ЭСФ | SAP ERP |
| Platts | Источник ценовых котировок | Рыночные цены для расчетов | SAP ERP |
| СИЗ | Контур данных по средствам защиты | Финансовые выгрузки и контроль | SAP ERP |

### 2.5 Информационная безопасность и ИТ-инфраструктура

| Система / компонент | Что это | Как используется | Ключевые связи |
|---|---|---|---|
| Solar Dozor (DLP) | Контроль утечек данных | Мониторинг каналов передачи информации | Exchange, Forcepoint, AD |
| Forcepoint Web Gateway | Защита веб-трафика | Фильтрация и контроль интернет-доступа | DLP |
| FUDOPAM (PAM) | Управление привилегированным доступом | Контроль администраторских сессий | AD |
| Microsoft Exchange | Почтовая платформа | Корпоративная коммуникация, контроль почтовых рисков | DLP |

### 2.6 Компоненты внутренней архитектуры ИМ (раздел 3/5)

| Компонент | Назначение | Использование в процессе |
|---|---|---|
| Cron | Планировщик задач | Запускает регулярные сборы и обновления |
| Скрипты сбора (Python ETL) | Интеграционный слой данных | Забирают данные по OPC/Modbus/SQL и обновляют локальную БД |
| Django-приложение | Прикладная логика | API, формы, обработка пользовательских сценариев |
| Celery | Фоновая обработка | Асинхронные задачи, рассылки, обработка пакетов |
| Локальная БД ИМ | Операционный storage | Хранит теги, скважины, отчеты и промежуточные результаты |
| Kepware OPC DA / OPC UA | Подключение к телеметрии | Получение промысловых параметров |
| Modbus TCP | Протокол промышленных устройств | Сбор показаний с узлов учета/оборудования |
| PostgreSQL / MySQL источники | Технологические БД | Чтение производственных данных и справочников |
| Аналитика ЭМГ (:8099) | Потребитель данных | Получает теги/скважины для аналитики |
| packet_service (:8951) | Потребитель событий/пакетов | Получает данные по реклоузерам |
| Speech API (:8777) | Распознавание речи | Преобразует аудио-рапорты в структурированные данные |
| SMTP | Уведомления | Рассылка отчетов и событий по почте |

### 2.7 Системы со специальным статусом в матрице

| Система | Статус в текущем контуре ЭМГ | Комментарий |
|---|---|---|
| АИСЭМ | Вне контура ЭМГ | Указана в матрице, но не участвует в текущей схеме |
| Work | Вне контура ЭМГ | Рекрутинговый сервис без интеграций в текущем ландшафте |
| ИС «Санау» | Выведена | Система в статусе вывода |
| Бюро пропусков | Отключена | Не используется в актуальном контуре |
| BoardMaps | Вне контура ЭМГ | Корпоративный сервис без связей в текущей схеме |

## 3) Как использовать справочник на встрече с бизнесом

1. Начать с раздела **«Компоненты схемы»** (что за блоки и кто за что отвечает).  
2. Затем перейти к разделу **«Справочник систем»** (роль каждой ИС в процессе).  
3. Для технических вопросов использовать раздел **2.6** и детальные схемы из [`architecture-emg-integrations.md`](architecture-emg-integrations.md).
