# Макеты: «Расчёт потенциала»

HTML-макеты web-страницы управления сценариями расчёта потенциала.

## Файлы

| Файл | Описание |
|------|----------|
| [index.html](index.html) | Список расчётов в хронологическом порядке |
| [calculation-detail.html](calculation-detail.html) | Drill-down: карточка выбранного расчёта |
| [styles.css](styles.css) | Общие стили |

## Открыть локально

```bash
cd docs/mockups/potential-calculations
python3 -m http.server 8080
```

Откройте http://localhost:8080/index.html

## Функциональность (макет)

### Список расчётов (`index.html`)

- **Хронологический порядок** — сценарии отсортированы по дате (по умолчанию «Сначала новые»)
- **Поиск** — поле «Поиск по ключевым словам»
- **Сортировка** — по дате создания / изменения (новые / старые)
- **Drill-down** — клик по названию расчёта (`>`) открывает карточку
- **Статусы** — «Выполняется расчёт» (синий) / «Выполнен» (зелёный)
- **Действия для завершённых**:
  - выгрузка в Excel
  - клонирование (создание копии сценария)
  - удаление
- **Для выполняющихся** — только отмена расчёта
- **Пагинация** — «1 – 8 из 8», навигация по страницам

### Карточка расчёта (`calculation-detail.html`)

- Параметры сценария (даты, автор, модель, источник ТМ)
- Хронология событий
- Фрагмент таблицы результатов
- Кнопки Excel / клон / удалить

## Соответствие референсу

Макет повторяет структуру предоставленного скриншота: заголовок, кнопка «Загрузить», поиск, сортировка, строки расчётов с метаданными и иконками действий, пагинация внизу.
