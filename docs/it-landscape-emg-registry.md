## Интеллектуальное месторождение (№19) — детализация интеграций

| Контрагент | Данные | Протокол | Частота |
|------------|--------|----------|---------|
| ИС ABAI (PostgreSQL) | Фонд скважин, статусы, техрежимы, история ремонтов | SQL (прямой запрос) | 08:00, 13:30, 18:00 |
| ИСУН (view в БД) | Уровни/объемы РВС, КУУН, температура, давление, плотность | SQL read (табличные данные) | каждые 2 часа |
| Общий сервер АСУТП Кайнармунайгаз | Узлы учета газа/нефти, уровни, давление, температура | OPC UA (Polling) | каждые 5 минут |
| Общий сервер ТМ АГЗУ Кайнармунайгаз | Замеры АГЗУ, теги температуры/давления, обводненность | MS SQL + OPC UA (Polling) | каждые 5 минут |
| КУУН НПС-3 | Накопленные объем/масса, температура, давление, плотность | Modbus TCP (Polling) | каждые 2 часа |
| СДМО | Состояние скважины и суточные показатели (время остановов, накопление) | MySQL (прямой запрос) | каждый час |

## SAP ERP (№18) — основные связи

| Контрагент | Данные |
|------------|--------|
| Нацбанк | Ежедневные официальные курсы валют (XML) |
| ИС ЭСФ | Информация по счетам-фактурам |
| БВУ | Банковские выписки и платежи (MT940/MT103) |
| Кадры / УП | Табельные номера сотрудников |
| 1С | Суммы заработной платы |
| FC | Данные финансовой консолидации (ЕКП) |
| ИС УТО | Данные по объектам, транспорту и операциям |
| SCADA | Данные по оборудованию |
| АСУНСИ | НСИ (SAP PO / XML) |
| AVR | Данные по договорам и актам выполненных работ |
| ЭА / Documentum | Карточки договоров, акты, накладные, фактуры |
| Platts | Котировки нефти (марка/сорт, дата) |
| СИЗ | Финансовые данные по СИЗ (XLSX) |
