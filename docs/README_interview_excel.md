# QA Interview Evaluation — Excel

Файл: **`QA_Interview_Evaluation.xlsx`**

## Листы

| Лист | Назначение |
|------|------------|
| **Инструкция** | Пороги решений, шкала баллов, порядок интервью |
| **Вопросы** | 20 вопросов, макс. 76 баллов + критерии 0–3 |
| **Кейсы** | Кейс A (e-com) или B (mobile), 4×6 = 24 балла |
| **Граничные** | 10 граничных проверок (опционально), отдельная шкала /10 |
| **Штрафы** | До −10 баллов |
| **Сводка** | Автоматический итог и Lead-пороги |
| **Карточка кандидата** | Итог для HR + комментарии |

## Как заполнять

1. Во время интервью вносите баллы в колонку **«Балл»** на листах «Вопросы», «Кейсы», «Граничные».
2. На «Кейсах» заполняйте **только 4 строки** выбранного кейса (A: строки 3–6 или B: 7–10).
3. На «Штрафах» укажите **да** в колонке «Применён».
4. Итог и решение появятся на **«Сводка»** и **«Карточка кандидата»**.

## Пересборка файла
