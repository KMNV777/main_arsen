Исходники Mermaid: `*.mmd` в этой папке. Файл `09-emg-c4-component.svg` генерируется отдельным скриптом (`scripts/build_emg_c4_component.py`), Mermaid-исходника не имеет.

Пересборка:

```bash
cd docs/svg
npx @mermaid-js/mermaid-cli -i 00-summary-architecture.mmd -o 00-summary-architecture.svg -b transparent
```
